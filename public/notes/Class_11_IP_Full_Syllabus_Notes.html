Chapter 1: Introduction to Computer System

CPU Architecture: ALU (Arithmetic Logic), CU (Control Unit), Registers.

Memory: RAM (Volatile, temporary), ROM (Non-volatile, BIOS firmware).

Secondary Storage: SSD, HDD, Flash Drives.

Software: System Software (OS, Compiler) vs Application Software.

Q1: What is the main difference between RAM and ROM?
RAM loses its data when powered off (volatile). ROM keeps bootup instructions permanently (non-volatile).

Chapter 2: Introduction to Python & Control Flow

Tokens: Keywords, Identifiers, Literals, Operators, Punctuators.

Operators: // (floor division), % (modulus remainder), ** (exponent).

# Python Control Flow
for i in range(1, 6):
    print(i, i**2)
Q1: What is the output of range(2, 10, 3)?
2, 5, 8

Chapter 3: Python Lists and Dictionaries

Lists: Ordered, mutable sequences indexed by position: [10, 20, 30].

Dictionaries: Unordered, mutable key-value collections: {'name': 'Aarav', 'marks': 95}.

Chapter 4: Database Concepts and SQL

Relational Model: Relation (Table), Attribute (Column), Tuple (Row), Degree (Col count), Cardinality (Row count).

CREATE TABLE Student (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50),
    Marks INT
);
SELECT * FROM Student WHERE Marks > 80 ORDER BY Marks DESC;

Chapter 5: Introduction to Emerging Trends

Technologies: Artificial Intelligence (AI), Machine Learning (ML), Big Data (5 Vs: Volume, Velocity, Variety, Veracity, Value), Cloud Computing (SaaS, IaaS, PaaS), Blockchain.
