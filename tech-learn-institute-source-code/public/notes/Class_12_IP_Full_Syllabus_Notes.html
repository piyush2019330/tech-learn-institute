Chapter 1: Data Handling using Pandas - I (Series)

1. Series Definition: A 1-Dimensional labeled array capable of holding any data type.

import pandas as pd
s = pd.Series([98, 95, 92], index=['IP', 'Math', 'English'])
print(s)

Key Attributes: s.index, s.values, s.shape, s.dtype, s.size, s.empty.

Q1: What happens during arithmetic operations between two Series with different index labels?
Pandas aligns elements based on index labels. Unmatched indexes result in NaN (Not a Number).

Chapter 2: Data Handling using Pandas - II (DataFrames & CSV)

1. DataFrame Definition: A 2-Dimensional labeled data structure with columns of potentially different types.

data = {'Student': ['Aarav', 'Priya'], 'IP_Marks': [98, 95]}
df = pd.DataFrame(data)
print(df[df['IP_Marks'] >= 95])

Indexing: df.loc[row_label, col_label] (label-based) vs df.iloc[row_pos, col_pos] (integer-based).

CSV Files: df.to_csv('marks.csv', index=False) and df = pd.read_csv('marks.csv').

Chapter 4: Database Querying using SQL Functions

Math Functions: POWER(m, n), ROUND(n, d), MOD(n, m).

String Functions: UPPER(), LOWER(), SUBSTR(), LENGTH(), INSTR(), TRIM().

Date Functions: NOW(), CURDATE(), DAYNAME(), MONTHNAME(), YEAR().

Aggregate Functions: SUM(), AVG(), MIN(), MAX(), COUNT(), COUNT(*).

Chapter 5: Querying with GROUP BY, HAVING & Multi-Table Joins

GROUP BY: Groups records sharing common values.

HAVING: Filters grouped records after aggregate evaluation.

Equi-Join: SELECT * FROM Student s, Dept d WHERE s.DeptId = d.DeptId;
